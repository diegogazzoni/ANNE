ANNE (Artificial Neural Network Engine)

# What is it
ANNE is a personal project to improve my confidence about the internal working of neural networks. Here all the required components are written from scratch. It is under development during free time, so bugs, errors and other artifacts must be expected.

# Some technical information
This library exposes some functions to create fully-connected neural networks and to train them with the stochastic gradient descent algorithm.
